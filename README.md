 # ShopZone 

ShopZone is a modern and responsive E-Commerce web application built using React.js and Tailwind CSS. The platform allows users to browse products, view detailed product information, manage cart items, and access protected checkout functionality with mock authentication.

---

##  Features

- Responsive modern UI
- Product listing page
- Product details page
- Add to Cart functionality
- Cart management using Context API
- Protected Checkout Route
- Mock Authentication (Login as Guest)
- Dynamic Routing using React Router
- Stylish homepage with hero banner
- Fully responsive design

---

##  Tech Stack

- React.js
- Tailwind CSS
- React Router DOM
- Context API
- JavaScript (ES6)

##  Installation

Clone the repository:

```bash
git clone <repository-link>
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

---

##  Authentication

Implemented mock authentication using Context API.

- Users can log in as Guest
- Checkout route is protected
- Unauthorized users are redirected to Login page
